## 輿圖導航器 - 根本性掉落關鍵字建議 (Fundamental Drop Keyword Recommendations)

如果您不想研究複雜的賽季機制，只想針對「最通用、最直接」的掉落與怪物增益，請在網頁搜尋框鎖定以下 4 個最根本的英文關鍵字：

### 1. Pack Size (怪的密度) —— 「怪越多」
這是所有掉落的基礎。搜尋這個關鍵字，它會增加每一群怪物的數量。
* **邏輯**：讓地圖裡的怪物更密集。怪越多，掉寶的判定次數就越多。

### 2. Quantity (物品掉落數量) —— 「掉越多」
這是最純粹的「量」。
* **邏輯**：直接增加所有物品（包括通貨、裝備、地圖）的掉落總量。

### 3. Rarity (物品稀有度) —— 「質越好」
提升掉落物品質的核心。
* **邏輯**：提升掉落裝備從「白色/藍色」變成「金色/獨特(傳奇)」的機率。

### 4. Modifier Effect (地圖詞綴效果) —— 「根本性的放大器」
這是讓上述三個屬性「翻倍」最強的手段。
* **邏輯**：直接「放大」地圖本身帶有的數量和怪物密度屬性。

---

**快速建議操作**：
* **想刷得爽（怪多）**：搜 Pack Size
* **想掉得多（發財）**：搜 Quantity
* **想掉得好（打寶）**：搜 Rarity
* **想全方位變強（核心）**：搜 Modifier Effect
